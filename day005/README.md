# かずをかぞえよう

画面に出てくるアイテムを数え、正しい数字を選ぶ子ども向けのミニゲームです。全 10 問で、答えるたびに正誤を確認できます。

## 特徴

- 1〜10 個のアイテムを数える全 10 問のゲーム
- 大きな数字ボタンとひらがな補助で、タップしやすいデザイン
- キーボード操作・スクリーンリーダーにも対応
- 外部通信なしでブラウザ内だけで遊べる静的サイト
- `NEXT_PUBLIC_BASE_PATH` によるサブディレクトリ配信に対応

## 開発

```bash
npm install
npm run dev
```

通常の開発サーバーでは `.env.development` によりルートパスで起動します。別の公開パスで確認する場合は、環境変数 `NEXT_PUBLIC_BASE_PATH` に先頭・末尾の `/` を除くパスを指定してください。

## 検証とビルド

```bash
npm test
npm run lint
npm run build
```

`npm run build` は静的ファイルを `out/` に出力します。本番用の公開パスは `.env` の `NEXT_PUBLIC_BASE_PATH` で設定します。favicon を含む静的アセット参照にも同じパスが適用されます。

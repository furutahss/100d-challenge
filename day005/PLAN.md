# Day005 実装計画

## 目的

幼児が画面に並ぶアイテムを数え、正しい数字を選ぶ知育ゲーム「かずをかぞえよう」を作成する。短いひらがなの案内、十分に大きなタップ領域、正解・不正解がすぐ分かるフィードバックを備え、スマートフォンでも遊びやすくする。

## 進め方

1. 仕様を確定する
   - 出題、解答、進行、画面、アクセシビリティ、テスト対象を `SPEC.md` に定義する。
   - 内容を確認いただき、明示的な承認を受けてから実装へ進む。

2. Next.js プロジェクトを準備する
   - `day005/` に Next.js（静的エクスポート）、TypeScript、Tailwind CSS、SCSS の構成を用意する。
   - Vitest と Testing Library をテスト環境として設定する。

3. TDD でゲームロジックを実装する
   - 先に出題生成、選択肢生成、解答判定、ラウンド進行の失敗するテストを書く。
   - 最小限の実装でテストを通し、出題の重複・範囲・状態遷移を整える。

4. TDD で画面を実装する
   - 問題表示、数字ボタン、フィードバック、結果画面をコンポーネントテストから実装する。
   - SCSS と Tailwind CSS で、子どもが押しやすいレスポンシブ UI に仕上げる。
   - アイテムの見た目にはテキスト絵文字を用い、外部画像への依存を持たせない。

5. 検証・セルフレビュー・文書化を行う
   - ユニットテスト、コンポーネントテスト、lint、production build を実行する。
   - 実装差分をセルフレビューし、指摘があれば修正して全検証を再実行する。指摘が 0 件になるまで繰り返す。
   - `README.md` に機能、実行方法、操作方法を記載する。

## 完了条件

- 1〜10 個のアイテムを数える全 10 問のゲームを最後まで遊べる。
- 正誤表示、スコア、もう一度遊ぶ操作が正常に動作する。
- テスト、lint、静的ビルドが成功する。
- セルフレビューの指摘が 0 件である。

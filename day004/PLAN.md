# Day004 実装計画

## 目的

ブラウザ内だけで画像を変換できる「画像サイズコンバータ」を作成する。複数画像を受け付け、ファイルサイズ指定と画像サイズ変更の2つのモード、および個別・一括ダウンロードを提供する。

## 進め方

1. 仕様を確定する
   - 入出力形式、各モードの挙動、制約、画面構成、エラー時の扱いを `SPEC.md` に定義する。
   - 内容を確認いただき、明示的なOKを受けてから実装へ進む。

2. Next.js プロジェクトを準備する
   - Next.js（静的エクスポート）、TypeScript、SCSS、Tailwind CSS の構成を `day004/` に作成する。
   - lint・テスト用の基本設定を加える。

3. TDDで変換ロジックを実装する
   - 最初に、入力検証・ファイル名生成・目標ファイルサイズ探索の失敗するテストを書く。
   - Canvas APIを用いる画像エンコード処理を実装し、テストを通す。
   - サイズ変更モードの寸法計算と変換結果の管理をテスト駆動で実装する。

4. UIとダウンロード機能を実装する
   - 複数ファイルの追加、設定、変換、プレビュー、個別ダウンロードを実装する。
   - ZIP形式の一括ダウンロードを実装する。
   - シンプルで操作に集中できるレスポンシブデザインをSCSSとTailwindで整える。

5. faviconを作成して反映する
   - 画像のリサイズを想起させる独自のfaviconを作成し、Next.jsのmetadataへ設定する。

6. 検証と文書化を行う
   - ユニットテスト、lint、production buildを実行する。
   - 実行方法・機能・制約を `README.md` にまとめる。

## 完了条件

- 仕様書で定義した主要操作がブラウザ上で完結する。
- 個別ダウンロードとZIP一括ダウンロードが動作する。
- テスト、lint、静的ビルドが成功する。
- faviconが反映されている。

# ダミー画像ジェネレーター

サイズ、背景色、ファイル形式を指定して、モックアップに使える画像をブラウザ内で生成するツールです。SNSカード、ブログ画像、プロフィール画像、スマホ壁紙、プレゼン、サムネイル、名刺、A4などのプリセットに対応しています。ベタ塗りのほか、グラデーション、ドット、グリッド、ストライプのデザインを選べます。すべての設定変更が自動反映され、専用の生成ボタンなしでダウンロードできます。画像データはサーバーへ送信しません。

## 開発

```bash
npm install
npm test
npm run lint
npm run build
```

静的exportで生成されるため、`npm run start` で `out` を確認できます。公開時のbasePathは`.env`の`/dummy-image-generator`、ローカル開発時は空の`.env.development`を使用します。
